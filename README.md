# Agriculture Performance Analysis

## Project Overview

Agriculture Performance Analysis is a Python-based Data Analysis and Machine Learning project that analyzes agricultural data to understand crop yield, profitability, irrigation, water usage, seed quality, and other factors affecting agricultural performance.

The project uses Python libraries for data cleaning, analysis, visualization, and machine learning. A Random Forest Regression model is also used to predict crop yield.

---

## Objectives

- Analyze agricultural performance using farm data.
- Perform exploratory data analysis on agricultural variables.
- Analyze crop-wise yield.
- Analyze season-wise profit.
- Compare profit across different states.
- Analyze irrigation methods and their effect on crop yield.
- Study the relationship between water usage and crop yield.
- Analyze the relationship between seed quality and crop yield.
- Analyze the distribution of agricultural profit.
- Identify relationships between numerical variables.
- Predict crop yield using Machine Learning.
- Identify important features affecting crop yield.

---

## Dataset

The project uses the following dataset:

`data/agriculture_performance.csv`

The dataset contains agricultural records with information related to:

- Crop
- State
- Season
- Rainfall
- Soil properties
- Irrigation
- Seed quality
- Yield
- Production
- Cost
- Revenue
- Profit
- Water usage
- Disease and pest risk
